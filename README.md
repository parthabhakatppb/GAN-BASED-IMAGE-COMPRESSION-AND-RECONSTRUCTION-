Object-Centric Image Compression: YOLOv8 + Object Stacking + GANAn end-to-end implementation of an object-centric image compression and reconstruction pipeline. The framework leverages YOLOv8-Seg for instance segmentation, packs high-priority object regions into a compact atlas using Object Stacking, compresses downscaled background elements separately, and reconstructs high-fidelity images refined by a GAN / Neural Refinement network.📌 Features & Pipeline OverviewObject Detection & Segmentation: Uses YOLOv8m-seg (or class-agnostic FFT spectral residual saliency detection) to identify foreground objects, extract segmentation masks, bounding boxes, labels, and confidence scores.Atlas Generation & Background Downscaling:Crops foreground objects and stacks them into a compact atlas texture without void space to minimize storage overhead.Separately downscales and compresses the background regions using adjustable JPEG quality factors (jpeg_q).Reconstruction & GAN Refinement:Upscales the background and stitches object crops back into their original pixel coordinates using JSON metadata.Enhances visual fidelity and removes compression/stitching artifacts using a GAN refinement network.Comprehensive Metric Suite: Evaluates quality vs. compression tradeoffs across standard image quality metrics:Compression Efficiency: Bitrate (bpp) & Compression Ratio.Fidelity & Perception: PSNR, SSIM, LPIPS, and VMAF.📂 Repository StructurePlaintext.
